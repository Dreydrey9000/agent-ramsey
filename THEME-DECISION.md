# Agent RAMsey visual identity

- Project: Agent RAMsey public repository and shareable artwork.
- Audience: Mac users and coding assistants exploring resource diagnostics.
- Selected by the project owner on November 11, 2026: **Option 2, Blacksite Operative** from the six-direction visual board.
- Structure: a wide editorial cover, a matching square character portrait and an illustrated feature briefing.
- Palette: warm ivory paper, near-black ink and burnt-orange accents. Text must remain readable against its background.
- Typography: condensed poster-style display lettering in artwork. Standard Markdown remains the documentation type.
- Character: an original illustrated ram agent with natural curled horns, a dark technical coat and a discreet earpiece. Calm and capable. No weapons or third-party logos.
- Material: visible paper grain and restrained ink wear. An orange diagonal accent supplies depth without obscuring content.
- Motion: static assets for GitHub. The optional dossier reveal discussed on the concept board is not implemented.
- Reference: the owner's selected concept board. Public research informed broad atmosphere only. No reference mascot or proprietary artwork is copied.
- Preserve: all commands, runtime behavior, setup instructions, privacy boundaries and truthful measurement limits.
- Verify: inspect every generated asset, check dimensions and size, add accessible text alternatives, verify relative image links and pass the public-file check plus repository CI.
- Scope: this choice applies to Agent RAMsey. It does not establish a default theme for other projects.
